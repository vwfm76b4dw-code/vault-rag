# Astra 设计简报 — vault-rag 控制台 UI 整体重做（8 面板）

> 用途：交给 GPT-6 Astra 生成设计规格 → 本地实现 → Astra 复评打分 → 迭代闭环。
> 本文件是闭环的固定输入包；Astra 的输出存 `docs/astra-design-spec.md`，评审记录存 `docs/astra-design-review.md`。

## 一、产品语境（设计必须服务于此）

- **定位**：用户与 AI 代理们的共享大脑（本地优先 Obsidian RAG），越用越准
- **双用户**：人（学生：错题拍照/教材检索/问答）+ AI 代理（MCP 32+ 工具的持久记忆后端）
- **用户审美批评史**：曾评"简陋廉价塑料感"；v1.2.2 起照 LM Studio 截图重做了侧栏与模型页（细图标侧栏+左列表/右详情），但其余页面仍是"表单堆"
- **设计参考**：LM Studio（信息密度/双栏结构）+ Apple HIG（质感/层次/呼吸感）
- **主题**：深色单主题、终端荧光绿 `#33ff33` 点缀（用户指定过的品牌色——是否保留/弱化请给出专业意见）

## 二、硬性技术约束

1. **离线可用**：无框架、无 CDN、无外部字体——原生 JS + 单 CSS 文件（webui_assets/style.css，当前 371 行）
2. 宿主是 pywebview/WebView2（Chromium 内核，窗口模式），也跑在浏览器 dev 模式；最小窗口宽度 ~900px
3. 中文界面（Segoe UI / 微软雅黑 回退），等宽用 Cascadia Code/Consolas
4. 交互全部走 fetch JSON API；改动需遵守 8pt 网格与既有 `?v=` 缓存参数纪律
5. 静态资源版本参数手写（`?v=1.2.4`），UI 重做时建议顺带给自动化方案

## 四、8 个面板清单（元素清单即信息架构，顺序即导航序）

1. **问答（检索）**：聊天流（气泡/流式光标/复制按钮）+ 3 个建议 chip + 输入区（发送/仅检索）+ 右侧来源面板（来源卡可点开原文、PDF 页命中可转笔记）
2. **看板**：报纸头条卡（知识库早报：头条/代理动作/近7天入库/今日待复习三栏）+ 6 张统计数字卡（countUp 动画）+ 领域分布条形图 + 知识关系图 + 权重榜 + 最近索引列表
3. **操作管理**：批量上传拖拽区（识图策略选择/价格估算/校准）+ include.txt 编辑器 + 添加外部文件/新建笔记 + 增量索引进度条+日志
4. **仓库管理**：仓库列表（切换/新建）+ 系统自检 + 索引统计卡 + 已索引笔记分页列表（搜索/领域筛选/移出索引）+ 库操作（清缓存/VACUUM/重建，危险按钮）
5. **生成供应商**：供应商列表（点击选中）+ 右侧详情面板（字段/启用切换/专用Key/删除）+ 新增/修改表单 + 测试连通（v1.2.3 已重排，本轮参考样板）
6. **检索 Embedding**：向量来源链卡（4 个 radio 后端模式）+ llama.cpp 状态 + 模型列表 + 右侧模型详情（字段/mmproj 配对/启用）+ HF 搜索/浏览/下载（队列进度）+ HTTP 端点档案（同样板）
7. **MCP & 状态**：Claude Code 注册状态 + 一键接入客户端列表（含配置片段兜底）+ 系统状态（kv 行）
8. **高级设置**：生成偏好（temperature/top_k/线程）+ 全局 API key + 问答后端接入配置（Base URL/Key/复制）+ 系统信息（环境变量说明）

## 五、期望 Astra 输出（设计规格书结构）

1. **全局设计令牌**：色板（含语义色）、间距尺度（8pt 网格）、字阶（中文适配）、圆角/描边/阴影体系、动效曲线——逐项给出可直贴 CSS 变量的值
2. **组件规格**：卡片/按钮（含危险/主/次）/表单/列表行/详情面板/进度条/日志区/空态——每组件给结构+样式要点
3. **每面板布局规格**：栅格、区块层级、留白节奏；指出哪些现有元素应合并/删除/降级
4. **质感升级专项**：如何去掉"塑料感"（阴影层次/描边策略/材质暗示），同时压制过度装饰（极光/噪点/光晕的去留）
5. **实现优先级**：P0/P1/P2 排序 + 每步可验收标准
6. 输出为可直接执行的中文规格书（不要客套话，不要泛泛而谈，每条给具体值）
