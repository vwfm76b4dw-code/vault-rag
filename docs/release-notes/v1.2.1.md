# vault-rag v1.2.1

承接 v1.2.0 的「灵魂」版本：问答成为开放后端、错题拍照复利、代理记忆心跳。

## 灵魂三件套（新增）

### 问答后端 · OpenAI 兼容端点
- `POST /v1/chat/completions`：把 vault-rag 加为任意 OpenAI 兼容客户端
  （Cherry Studio / ChatBox / agent CLI…）的「供应商」，提问自动检索注入知识库
- 支持流式 SSE 与非流式；Bearer key 鉴权（首用自动生成，设置页可见）
- 高级设置页新增「问答后端」卡片：Base URL / Key / 一键复制接入配置

### 错题本 · 拍照复利（学习场景）
- 上传页拖入图片自动走错题链路：视觉模型识别题干与作答 → AI 批改
  （正解 / 错因 / 知识点）→ 生成结构化错题笔记入 `vault/错题/`，全文可检索
- frontmatter 带 `review_due`，次日进入复习队列；原图自动留档
- 看板「今日待复习」栏目：错题到期提醒（复利第一步）

### 记忆流 · 知识库早报（代理共享大脑的心跳）
- MCP 写入工具（write/update/delete/restore_note）挂活动钩子，
  代理每次写入/修改记忆都进 JSONL 事件流
- 看板页顶部「知识库早报」头条：最新代理动作 + 近 7 天新入库 + 今日待复习

## 修复

### 上传：图像/二进制不再静默吞掉（v1.2.0 实测黑洞）
- 上传端点按**扩展名 + magic bytes** 双重判定（改名 `.txt` 的图片也拦得住）
- 图像/二进制文件**不入盘、不写范围规则**，明确提示「图片暂不支持索引（多模态索引规划中）」
- 全部被拒时前端显示 ✗ 失败态，不再误报「已入库」
- 正式多模态方案（图像 embedding / 图片→描述）规划中，模块位于 `vault_rag/multimodal/`

### 仓库管理页复活（v1.2.0 起后端路由整组漏接）
- 补齐 `/api/repo/stats`、`/api/repo/notes`（GET 浏览 / DELETE 移出索引）、
  `/api/repo/clear-cache`、`/api/repo/vacuum`、`/api/repo/rebuild` 六条端点
- 统计卡片、已索引笔记列表/分页/搜索/领域筛选、「移出索引」「清缓存」「VACUUM」「全量重建」全部恢复可用
- 修复 `vacuum()` 两处变量引用错误（该函数此前从未跑通）

### 其它
- 恢复 IA 重构时丢失的仓库页统计卡片容器（僵尸 id 审计归零）
- 检索质量：上传文件内容级去重、文件名精确锚定（冒泡排序.cpp rank 5→1）

## 工程卫生

- `data/` 运行产物全面退出 git 跟踪（嵌套路径 DB 曾漏网入库）；`.gitignore` 嵌套规则加固
- 一次性补丁脚本下线（git 历史可找回）；过时实验产物归档 `data/_archive/`
- 测试套件 59 → 66 用例（上传分类/端点行为/仓库操作流）

## 升级

解压覆盖即可；`data_dir.txt` / `repos.json` 指针与既有数据目录自动沿用。
