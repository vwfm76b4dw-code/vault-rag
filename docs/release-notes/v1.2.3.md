# vault-rag v1.2.3

承接 v1.2.2。本版主题：**索引可靠性闭环 + 控制台界面 LM Studio 式重做**。安装包与便携 zip 双形态不变。

## 索引可靠性闭环

- **索引器二进制门禁**：读首 4KB 判二进制跳过——此前 uploads 里的图片会被按文本强解码成乱码块入库（实测 81,216 块污染，已备份清除并全量重建，索引 100% 配对一致）
- **批次进度日志**：`embed_batch` 每批输出进度，巨量文本块编码不再"静默数十分钟像死机"
- **索引停滞看门狗**：停滞 5 分钟自动终止并可用 py-spy 抓栈（配合 CPU 10 核事故的排查工具链）

## include.txt 语义定稿

- 采集范围声明**全局共享一份**：所有仓库同一 include 范围，由系统统一管理（纠正"每库一份"造成的新库不同步问题——两轮实测摇摆后的最终定稿）

## 控制台 UI 重做（LM Studio 式）

- **细图标侧边栏**：44×40 图标按钮、分组 1px 分隔细线、8pt 网格间距（修复分隔符渲染成灰色块：旧 padding 在 border-box 下撑破 1px 高度）
- **检索 Embedding 页**：模型列表 + 右侧详情面板（量化/架构/大小/用途），mmproj 视觉投影配对选择，HF 搜索/浏览/下载一条龙（含 401 拼写检查提示）
- **生成供应商页**：同款左列表/右详情重排——点击查看档案详情，「启用并切换 / 设置专用 Key / 删除」收进详情面板；新增选中高亮
- **导航吞词修复**：多词标签（⟳ 索引 · 范围 · 上传）不再被贪婪切分竖排挤字
- **窄窗口适配**：单列折叠时详情面板取消 sticky 吸附（不再钉在视口顶部）
- **WebView2 缓存坑**：根路由 no-cache + 静态资源 `?v=` 版本参数，frozen exe 重建后不再渲染旧 UI

## 安装

- 下载 `vault-rag-v1.2.3-setup.exe` → 双击 → 完成后桌面/开始菜单启动（免管理员，per-user 安装）
- 静默安装：`vault-rag-v1.2.3-setup.exe /VERYSILENT`（可选 `/DIR=目标目录`）
- 数据目录沿用安装目录 `data\`（`data_dir.txt` 可指向任意既有库）
