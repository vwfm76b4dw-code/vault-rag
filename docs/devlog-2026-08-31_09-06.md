# vault-rag 开发全史与真实认知（2026-08-31 ~ 09-06 汇总档案）

> 本文是主档案；细节散页见 [[vault-rag-project]]（架构/约定）、[[vault-rag-todo]]（滚动待办）。

## 一、对项目的真实认知（最重要）

1. **双用户产品**：vault-rag 同时服务两个人类/AI 两类用户——人用 Web 控制台（FastAPI+pywebview，端口 8765/8899），AI 代理经 MCP（rag-obsidian 32+工具 / vault_rag.rag_mcp 5 工具）把它当持久记忆。任何改动要同时考虑两个入口。
2. **用户真实画像**：学生（上传 98 个 cpp/拍错题照/传教材 PDF），不是开发者。核心场景按优先级：同步 AI 操作 > 错题拍照学习 > 了解 AI 行为 > 问答 > 展示（装逼）。
3. **灵魂定位（用户访谈定稿）**：代理的共享大脑，**持续复利，越用越准**。四个模块 = 问答开放后端（当后端不当页面）/ 错题拍照 / 记忆流心跳 / 报纸头条简报。
4. **发布纪律**：对外走 release 分支（squash 风格），本地 main 保留完整历史；v1.2.2 起提供 Inno Setup 安装包（353MB）+ 便携 zip 双形态。

## 三、事故与教训（全部实测踩中，违反=返工）

1. **heredoc 三大坑**：截断/转义（\n 双层求值变真换行写坏文件）/嵌套失效 → **补丁一律 Write 工具写脚本文件再执行**，已违反三次。
2. **WebView2 启发式缓存**：frozen exe 重建后窗口渲染旧 UI 数天不过期 → 根路由 no-cache 头 + 资源引用 ?v=版本。
3. **--noconfirm 清 dist**：构建后必须恢复 data_dir.txt/repos.json/llama/ 三件套 → scripts/build_exe.py 一体化（漏 llama = 内置嵌入链未就绪）。
4. **正则两段式 ([^<]+) ([^<]+) 切分**：多空格标签（⟳ 索引 · 范围 · 上传）被贪婪吞词 → icon 格吞掉大半文字竖排挤字 → 首 token 切分。
5. **模块 __getattr__ shim**：测试置 scope.INCLUDE_PATH 属性会永久遮蔽 → 统一函数 include_path()。
6. **注入代码绝不能追加在 mcp.run() 之后**（stdio 阻塞永不执行）→ 守卫前插入；py-spy 验证钩子看 __wrapped__。
7. **FTS5**：中文必须 trigram 分词 + CJK 2-gram 兜底；bm25 负分要 abs 归一。
8. **curl 中文 body**：Git Bash 会搞坏编码 → python requests 或文件体。
9. **索引器二进制防线**：uploads 全收文件（含图片），errors=replace 会把图片变 8 万块乱码 → 首 4KB 判二进制跳过。
10. **embed_batch 静默批**：巨量文本块 CPU 计算数十分钟无输出像死机 → 批次进度日志。
11. **静态绑定坑**：repos.apply_data_dir 改 config 属性，webui_lib 的 import 时绑定不跟随（LOCAL_SETTINGS_PATH 曾因此不切换）。
12. **个人路径红线测试**会抓 scripts 下硬编码路径 → 新脚本一律 __file__ 推导。
13. **窗口模式 exe 不打"服务运行中"日志**：探活用 netstat 按 PID；页面失联=窗口被关静默退出。
14. **FastAPI 0.141**：include_router 包成 _IncludedRouter，app.routes 内省看不到；PyInstaller 包内验证用 ZlibArchiveReader。
15. **CPU 事故根因未根治**：索引子进程加载 VL compressed-tensors 模型解压死锁 4 天（10 线程空转）——下次复现用 py-spy 抓栈（Scripts/py-spy.exe 全路径），并加模型加载看门狗。
16. **CSS 源序覆写坑**：同特异性规则（如 `#id{position:sticky}`）写在 `@media` 块之后会覆盖查询内的 `static`——响应式覆盖必须源序在前；且 UI 修复验证要量 `getComputedStyle`，单看截图会被过渡帧（面板空白）和覆盖失败（布局对但行为错）骗过。
