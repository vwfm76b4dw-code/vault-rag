## 双评设计（客观性来源）

- **管线输出**：生产提示词（错题整理助手）→ 结构化笔记。
- **独立参照**：同一图片、**不同提示词、独立 API 调用**——
  ①纯 OCR 转写印刷题干（与笔记无关的参照系）；②独立批改老师（只输出 JSON 的另一套提示词）。
- 分歧与一致性全部机算，评审者只核验计算与阈值是否被遵守。

## 指标与阈值

| # | 指标 | 口径 | 阈值 |
|---|------|------|------|
| M1 | 确定结局率 | 每张照片=入库 或 带原因的明确拒绝（黑洞回归指标，静默丢弃=0 分） | =100% |
| M2 | 结构完整率 | 六字段（题目/我的答案/正确答案/错因分析/知识点/解法）非空占比 | ≥95% |
| M3 | Frontmatter 合规 | type/created/subject/tags/review_due/source 六键齐全 | =100% |
| M4 | 题干保真度 | 笔记"题目" vs 独立 OCR 参照的 difflib 相似度均值 | ≥0.60 |
| M5 | 批改双评一致性 | 正确答案相似≥0.5 且 答对/答错方向与独立批改一致 | ≥80% |
| M6 | 知识点规范性 | 1≤数量≤6 且 命中预置初中数学词表(56词)比例≥60% 的笔记占比 | ≥60% |
| M7 | 拒绝均带原因 | 所有明确拒绝都包含"不是题目"类可读原因 | =100% |
| M8 | 复习调度正确 | review_due = created + 1 天 | =100% |

**总判定**：8 项中 ≥7 项达标 = PASS；M1 或 M7 失败 = 一票否决（黑洞与幻觉是硬伤）。

## 已知局限（评审时须知）

- M4 手写干扰会压低相似度，0.60 是宽松线；低于它只说明题干转写漂移，需人工抽查
- M5 双评同模型（Agnes），存在共同偏差；它测"管线输出的自洽性"而非绝对对错
- 页码/分数等符号 OCR 漂移属正常；报告保留逐张明细供追溯
